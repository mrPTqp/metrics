Добавьте возможность обмена данными между сервером и агентом по протоколу gRPC. Агент должен отправлять метрики на сервер батчами.
Для этого определите следующий протокол в файле metrics.proto:

syntax = "proto3";

package metrics;

// При необходимости поправьте go_package в соответствии со структурой вашего проекта.
option go_package = "github.com/your-repo/your-project/internal/proto";

// Metric определяет единичную метрику.
message Metric {
  string id = 1; // имя метрики

  // MType задаёт тип метрики.
  enum MType {
    GAUGE = 0;
    COUNTER = 1;
  }

  MType type = 2; // тип метрики
  // Поле delta для метрик-счётчиков.
  int64 delta = 3;
  // Поле value для метрик-измерителей.
  double value = 4;
}

// UpdateMetricsRequest содержит список метрик для обновления.
message UpdateMetricsRequest {
  repeated Metric metrics = 1;
}

// UpdateMetricsResponse — пустой ответ для подтверждения успешного обновления.
message UpdateMetricsResponse {}

// MetricsService определяет сервис для работы с метриками.
service Metrics {
  // UpdateMetrics обновляет метрики на сервере.
  // Этот метод подходит для отправки как единичных метрик, так и батчей.
  rpc UpdateMetrics(UpdateMetricsRequest) returns (UpdateMetricsResponse);
} 
Требования к реализации:
Агент должен формировать UpdateMetricsRequest со списком собранных метрик и отправлять его на gRPC-сервер.
Сервер должен реализовать сервис Metrics и метод UpdateMetrics, который будет принимать и сохранять метрики.
Передача IP-адреса. Для проверки подсети на сервере агенту необходимо передавать свой IP-адрес. В gRPC для этого используются метаданные. Агент должен добавлять свой IP-адрес в метаданные запроса, например, с ключом x-real-ip.
Проверка подсети. На сервере должен быть реализован UnaryInterceptor, который проверяет, принадлежит ли IP-адрес агента доверенной подсети (trusted_subnet). Если проверка не пройдена, сервер должен возвращать ошибку с кодом codes.PermissionDenied.
Конфигурация. Все новые параметры (например, адрес gRPC-сервера) должны настраиваться через переменные окружения и флаги командной строки, аналогично существующим параметрам.
